Historical claim: killed

The old coordination meter could not measure coordination.

The source-space branch used pointwise

PLV(t) = |exp(i Δφ(t))| = 1

for every phase difference. Its “phase-slip” value was therefore zero and Y×PLV collapsed to Y. A second bug merged selected orchestra bands into one min→max filter, potentially putting the excluded conductor band back in.

Those screenshots are provenance, not evidence.

What survives

Spatial wave geometry is a legitimate object.

The repaired PAC branch measures association. The new branch asks something different: estimate a spatial phase gradient, turn it into a propagation-direction proxy, then test whether that geometry improves prediction of subsequent fast-band spatial motion.

The new measurement
1

Phase field

Band-pass a prespecified slow rhythm and estimate instantaneous phase at positioned sensors.

2

Spatial gradient

Fit wrapped phase differences across neighboring sensors to obtain ∇φ. Use −∇φ as a direction proxy.

3

Fast trajectory

Track the centroid of relative fast-band analytic amplitude and measure its future displacement.

4

Attack it

Require circular-shift advantage and blocked-CV predictive gain. Do not tune until a result appears.

Reality layer

Why the question is not nonsense.

  • Mohan et al., Nature Human Behaviour (2024): theta/alpha traveling-wave direction changed with human memory encoding vs recall in intracranial recordings.
  • Koller et al., Nature Communications (2024): connectome structure was modeled as shaping cortical traveling-wave directions and frequency gradients, with empirical MEG comparisons.
  • Traveling waves in human visual cortex (2025): model-based MEG/EEG work emphasizes how hard it is to infer cortical waves from non-invasive sensor measurements.
  • Traveling waves link visual and frontal cortex (2025): EEG wave direction related to memory-guided behavior.
Hard boundary

Why a pretty EEG arrow can still be wrong.

Sensor-space phase gradients can be distorted by volume conduction, source mixing, reference choice, spatial sampling, filters and non-sinusoidal waveform shape. High-frequency scalp EEG is also vulnerable to EMG.

The code therefore starts as a screening instrument. A serious positive should freeze bands/lag/reference, replicate on held-out subjects or recordings, and ideally survive a source-aware or intervention-based test.

The 2025 phase-locked stimulation dataset already taught this repo a useful lesson: matched timing can change responses without satisfying our stronger “more reachable dimensions” hypothesis.

Run it

New Python path

python pilot_field_explorer.py recording.edf --start 0 --duration 60

Defaults: alpha 8–12 Hz as the slow phase field, 30–45 Hz as the fast amplitude field, 80 ms future lag, and 200 circular-shift surrogates. Defaults are starting assumptions, not discoveries.
